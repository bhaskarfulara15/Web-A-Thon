# NIRVAN '26 — College Fest Website

A modern, futuristic and responsive website for **NIRVAN '26**, designed with a dark neon-themed UI, event showcase, registration system, and event galleries.

## ✨ Features

- 🌌 Futuristic dark UI design
- 💜 Neon purple/blue gradient theme
- 📱 Fully responsive design
- ⏳ Countdown timer for the fest
- 🎭 Event showcase section
- 🖼️ Event gallery system
- 🔍 Individual event gallery view
- 📝 Single-student registration
- 👥 Team/multiple-student registration
- 📋 Google Form integration for team registration
- ✨ Glassmorphism cards and glowing effects
- 🎨 Smooth hover and transition animations
- ⚡ Lightweight HTML, CSS and JavaScript implementation
